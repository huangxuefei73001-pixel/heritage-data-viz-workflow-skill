# Observation Poster Design Language

## Positioning

This visual language turns long-running heritage observation, research or monitoring data into one information object. It should feel closer to an editorial research poster, exhibition graphic or data-journalism feature than to a BI dashboard.

## Signature composition

The strongest samples use one of four compositions:

1. **Full radial chronology** - a circular time structure is the dominant evidence object.
2. **Metric manifesto** - a few numbers establish scale while a large title carries the narrative.
3. **Split field** - title/access/provenance on one side, dense circular evidence on the other.
4. **Sankey editorial** - weighted categorical flows occupy the evidence field on warm paper.

## Hierarchy

A poster should typically contain:

- a small series label;
- one large title or proposition;
- one dominant data visual;
- one compact legend;
- 2-4 supporting metrics at most;
- date range/source/QR/credits;
- optional back-side context.

Do not place several equally important charts on one page.

## Color

Use category colors consistently across all visual forms. A theme represented in a radial chart should keep the same color in a Sankey, legend and supporting graphic.

Dark analytical mode uses color mainly for data marks against charcoal.
Warm-paper mode uses the same categories with lower visual saturation and more whitespace.

Never change colors merely to make adjacent sections look different.

## Radial systems

Use radial chronology when annual/session rhythm is part of the claim.

- order rings or sectors consistently;
- label only the years/sessions required for orientation;
- use category bands rather than decorative arcs;
- reserve the center for a QR/access point only when this does not obscure interpretation;
- keep a stable legend outside the main circular field when possible.

## Sankey / alluvial

Use when the relationship between two or three categorical dimensions is the story.

- band width represents count/weight;
- labels remain legible without hover in poster exports;
- avoid crossing complexity when aggregation can clarify the pattern;
- use left/right or top/bottom ordering to support comparison;
- show total record coverage near the visual.

## Numbers

Large numbers are useful only when they establish scale or a meaningful threshold. Use 3-5 high-value metrics, not a KPI dashboard.

## Two-sided format

Front: pattern / relationship / evidence.
Back: project context / chronology / provenance / access.

The back should be quieter and more editorial than the front.

## Failure signals

Revise when the result resembles:

- a generic analytics dashboard;
- an infographic filled with icons;
- a chart collage;
- a decorative circular graphic whose arcs do not map to data;
- a poster where the QR code is more prominent than the research insight;
- a page where the viewer cannot tell which relationship matters most.
