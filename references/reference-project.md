# Reference Project — Observation Report Series

The Skill was distilled from a visualisation exercise for a multi-year World Heritage Committee Observation Report series.

The supplied reference material demonstrates four complementary ways to compress a large research archive into poster-scale evidence.

## Reference A — Theme-to-period relationship flow

The paper-field poster maps **197 observation items** from the 2013–2025 series into seven thematic categories and connects them to host-country / year contexts.

Published thematic totals in the supplied reference are:

| Theme | Items |
| --- | ---: |
| List Management | 58 |
| Annual Highlights | 42 |
| Forums & Events | 25 |
| Thematic Research | 23 |
| Convention Mechanisms | 19 |
| State of Conservation | 17 |
| Convention Priorities | 13 |

The design lesson is not “always use Sankey”. The lesson is that a many-to-many research archive can become legible when one dimension is stabilised as a taxonomy and the other as a repeated context.

## Reference B — Radial overview

The dark-field radial poster compresses repeated years / sessions and a seven-theme legend into one circular field.

The important design lesson is the combination of:

- chronology;
- recurring thematic tracks;
- category colour stability;
- one dominant visual object;
- a small number of corpus metrics below the main graphic.

## Reference C — Corpus-scale metrics

A second dark-field poster reduces the archive to four memorable figures:

- **13 years** — 2013–2025;
- **11 sessions** of the World Heritage Committee;
- **197 articles** / observation and commentary items;
- **36 reports**.

This is a useful reminder that a complex data project does not always require a complex chart. When the question is scale and continuity, a metric composition may be more truthful.

## Reference D — Timeline and explanatory reverse

The explanatory page uses a simple series timeline and institutional / publication context rather than repeating the dense data visualisation.

This establishes a reusable two-sided logic:

**Front:** one evidence-rich visual argument.  
**Back / supporting page:** methodology, context, timeline, credits, and access information.

## What is reusable

Reusable:

- corpus → taxonomy → relationship logic;
- dominant visual evidence;
- stable semantic category colours;
- dark and warm-paper surface modes;
- strong numeric anchors;
- front / supporting-page separation;
- source and access information kept visible.

Not automatically reusable:

- the exact radial geometry;
- the exact category taxonomy;
- the exact colours;
- QR placement;
- institutional marks;
- any specific count outside its original evidence context.

The Skill therefore generalises the **reasoning workflow**, not the branding of the reference project.
